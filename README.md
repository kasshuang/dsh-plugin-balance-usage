# dsh-plugin-balance-usage · 侧栏余额与用量

在 DeepSeek Harness（DSH）左侧栏底部加一个入口，直接把 **账户余额** 和 **今日 Token 用量** 摆在手边；点开面板可以看累计用量、近 14 天走势、按运营商 / 模型分组折叠与「主线」设置，并在应用内直接打开官方用量页。

## 功能

- **侧栏常驻入口**：宽栏显示「余额 + 今日用量」，折叠成窄轨时显示图标 + 状态点；数字自己刷新（关着 30 秒、开着 15 秒，窗口切回前台立刻补一次），不用点开也能看到变化。
- **账户余额**：来自 DeepSeek 平台账户接口（与「设置 → 账号与余额」同源），区分充值余额与赠送余额。
- **Token 用量**：读取本机会话日志（`~/.dsh/sessions/**/session.v4.jsonl.zstd`）汇总今日 / 累计 / 输入 / 输出 / 缓存读取与近 14 天柱状图。
- **多运营商 / 多模型**：按 `provider → model` 分组，可折叠；点星标把某个模型设为「主线」，侧栏显示的数字跟随主线（未设置时自动取最近使用的模型）。
- **官方用量详情**：面板底部按钮。桌面版在 **主内容区** 里以标签页打开官方 `platform.deepseek.com/usage`（复用宿主已注入的账号态，无需重新登录、不跳浏览器）；Web 版退化为新标签页打开。
- **跟随主题与语言**：只用 `--dsw-alias-*` 主题变量，浅色 / 深色 / 跟随系统均可；中英文随界面语言切换，含键盘可达（Esc 关闭、焦点回到入口、Tab 循环）。

## 安装

在 DSH 里打开 **插件 → 添加插件 → 安装 npm 包**，输入：

```
dsh-plugin-balance-usage
```

安装后侧栏底部立即出现入口（客户端插件热载生效，必要时刷新页面）。

### 从市场索引安装

若你的 DSH 已添加下列索引源，可直接在 **插件 → 发现** 里点安装：

```
https://cdn.jsdelivr.net/gh/kasshuang/dsh-plugin-balance-usage@main/market/index.json
```

## 数据与隐私

- 余额通过 DSH 官方的 `deepseekAccount` Remote 读取，本插件不接触、不保存任何凭据。
- 用量由 **本机** 会话日志聚合而成，不上传任何数据；扫描结果在内存中缓存 20 秒。
- 面板里「近 N 天 · M 次请求」的口径是 **本机会话**，因此可能小于平台账单（平台统计所有客户端与 API 调用）。

## 已知限制

- 应用内用量页仅在桌面版可用（浏览器没有 `dshPlatform` 桥，回退为外链）。
- 历史用量依赖本机会话日志；换机或清理 `~/.dsh/sessions` 后统计从零开始。
